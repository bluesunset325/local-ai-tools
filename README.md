# Local AI Tools

Два инструмента для работы с локальными моделями на Mac. Всё работает без облака: данные не покидают машину.

## `router.py` — роутер запросов по моделям Ollama
Сам выбирает модель под запрос: простые вопросы отправляет лёгкой модели, сложные — тяжёлой.

| Ветка | Модель | Для чего |
|---|---|---|
| nano | qwen2.5:3b-instruct | короткие ответы, всегда в памяти |
| light | qwen2.5:7b-instruct | обычные вопросы |
| mid / heavy | qwen3:14b (heavy — с reasoning) | код, вычисления, многошаговые задачи |
| vision | qwen3-vl:8b | изображения |

Если лёгкая модель сама признаёт, что запрос ей не по силам, он автоматически уходит к тяжёлой. Каждый запрос пишется в `log.jsonl` для статистики.

```bash
python3 router.py "текст запроса"
python3 router.py --model 14b "форсировать модель"
python3 router.py --stats
```

## `draw.sh` — генерация картинок через Flux (mflux, MLX)
```bash
./draw.sh "кот в космосе"            # 768×768, быстро
./draw.sh "кот в космосе" fullhd     # пресеты: square, portrait, landscape, hd, fullhd, story, 2k, 4k
./draw.sh "кот в космосе" 1024x768 4 # свой размер и число шагов
RAW=1 ./draw.sh "a cat in space"     # без перевода
```
Русский промпт автоматически переводится на английский локальной моделью через Ollama: Flux заметно точнее понимает английские описания.

**Требования:** macOS на Apple Silicon, [Ollama](https://ollama.com), `pip install mflux`.
